Installation Rapide dans ATAS X

🪟 1. Installation sous Windows

Copiez le fichier FootprintHvnLvnAbsorption.dll téléchargé ci-dessus dans votre dossier d'indicateurs ATAS :

%USERPROFILE%\Documents\ATAS\Indicators
  • Si Windows affiche un blocage de sécurité externe : clic droit sur la .dll → Propriétés → cochez Débloquer (Unblock).
  • Dans ATAS X, ouvrez Indicators (Ctrl+I) → catégorie Order Flow - Custom → ajoutez Footprint HVN / LVN & Heavy Absorption.

🍎 2. Installation sous macOS (ATAS X)

Placez le fichier FootprintHvnLvnAbsorption.dll dans le répertoire utilisateur ATAS sur votre Mac :

~/Documents/ATAS/Indicators/
  • Binaire compilé en .NET 10.0 multi-plateforme compatible nativement avec le moteur de rendu OFT.Rendering d'ATAS X.
  • Aucune dépendance tierce requise : le fichier .dll unique suffit.

🎯 3. Détails de la Détection Order Flow

  • HVN Intra-Bar & Composite : Identifie les pics locaux de volume (≥ % du POC) par bougie ainsi que les bandes HVN du profil de volume glissant ou de session.
  • LVN Intra-Bar & Composite : Cible les creux de liquidité internes situés entre deux zones denses (≤ % du POC, hors dernier tick de mèche).
  • Heavy Absorption : Détecte les volumes extrêmes (≥ 1.6x la moyenne de la bougie) avec forte dominance Bid ou Ask (≥ 62%), imbalance diagonale et clôture de rejet, puis projette un rayon S/R jusqu'à cassure du niveau.
